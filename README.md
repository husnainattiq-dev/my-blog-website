# My Blog Website
A personal blog website built using HTML5 and CSS3.

## Overview
This project features a clean blog layout
with a main content section and a sidebar
for author information and popular posts.

## Features
- Blog post cards with images
- Author profile section
- Popular posts sidebar
- Tags and categories
- Read More buttons
- Previous and Next navigation

## Technologies Used
- HTML5
- CSS3

## Getting Started
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
